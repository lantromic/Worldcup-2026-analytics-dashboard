
# World Cup 2026 Player Analysis Dashboard

An interactive web dashboard built with **Streamlit** and **Seaborn** to analyze player statistics, discipline profiles, shooting efficiency, and age trends for the 2026 FIFA World Cup.

---

## 🚀 Features

- **Dynamic Player Filters:** Filter by position, age range, national team, and club.
- **Discipline Analytics:** Examine fouls committed vs. fouls suffered per 90 minutes.
- **Finishing Efficiency:** Interactive scatter plots comparing goals against shots on target.
- **Age Trends:** Breakdown of goals, assists, and defensive metrics across age brackets.

---

## 🛠️ Installation & Setup
pip install -r requirements.txt
streamlit run my_app.py
